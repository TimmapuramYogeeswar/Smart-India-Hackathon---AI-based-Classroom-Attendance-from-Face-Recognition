# 2–3 Minute Demo Script

## 0:00–0:25 — Registration
"First, the teacher opens the student registration page. We can add a student's roll number, name, class and section. The information is stored in the SQLite database."

## 0:25–1:00 — Classroom detection
"Next, the teacher uploads a classroom photograph. The computer-vision module detects visible faces using OpenCV. The system reports how many faces were detected. This stage is face detection, not identity recognition."

## 1:00–1:45 — Attendance verification
"Now we open the dashboard. The complete class roster is shown with Present or Absent status. The teacher can verify and correct any entry. This keeps the final attendance decision under teacher control."

## 1:45–2:15 — Dashboard
"The dashboard gives the total class size, present count, absent count, and attendance percentage. A date selector allows the teacher to review another day's records."

## 2:15–2:35 — Export
"Finally, the teacher clicks Export CSV. The system generates a spreadsheet-compatible attendance report containing roll number, name, class, status, verification state, and date."

## Closing
"This prototype combines computer vision, a web dashboard, and database storage into one practical classroom attendance workflow."
